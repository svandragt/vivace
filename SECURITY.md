# Security

## Report a problem

Report a security problem privately, not in the issue tracker. Use GitHub's
[private vulnerability reporting](https://github.com/svandragt/vivace/security/advisories/new)
for this repository, or email sander@vandragt.com.

Say which viv version you ran, the command, and how to reproduce it. The
output of `viv diagnose` helps and prints no secrets.

## What to expect

One person maintains viv. Expect an acknowledgement within a week. A fix
ships in the next release and the advisory names the versions it affects.

## Supported versions

Only the latest 0.x release gets fixes. Upgrade before reporting if you can.
