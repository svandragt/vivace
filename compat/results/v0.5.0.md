# Compatibility sweep — v0.5.0

Composer install flags: `--no-scripts --no-plugins --no-interaction`; viv gets the same plus `--no-plugins` (viv refuses plugin-using projects otherwise).
Composer update flags, used only to generate a missing lock: `--no-scripts --no-plugins --no-interaction --ignore-platform-reqs`.
A project whose platform requirements aren't met is reported as `skipped: platform`, not a failure.
Git-source checkouts have their `.git` stripped before installing, so the vendor diff excludes `.git` metadata on both sides.
